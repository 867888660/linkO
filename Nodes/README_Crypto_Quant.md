# Crypto 量化分析工作流使用说明

## 新增节点

本次更新添加了3个新节点，用于支持 Crypto 类预测市场事件的量化分析：

### 1. Crypto_ParseQuestion.py
**功能**：从自然语言问题中提取加密货币信息
- 输入：`question`（问题描述）、`keywords`（可选关键词）
- 输出：JSON，包含 `symbol`、`binance_symbol`、`target_price`、`direction`、`time_condition`

**示例**：
```
输入: "Will BTC reach 120000 USD by March 2026?"
输出: {
  "symbol": "BTC",
  "binance_symbol": "BTCUSDT",
  "target_price": 120000.0,
  "direction": "bullish",
  "time_condition": "by March 2026"
}
```

### 2. Crypto_Klines.py
**功能**：从 Binance 获取历史K线数据并计算技术指标
- 输入：`Symbol`（如BTCUSDT）、`Interval`（如1d）、`Limit`（K线数量）
- 输出：JSON，包含 K线数据、MACD、RSI、SMA、EMA、布林带等技术指标

**技术指标**：
- MACD(12,26,9)
- RSI(14)
- SMA(20,50)
- EMA(12,26)
- 布林带(20,2)

**信号判断**：
- 趋势方向（多头/空头）
- MACD金叉/死叉
- RSI超买/超卖
- 均线交叉
- 布林带突破

### 3. Crypto_QuantReport.py
**功能**：将技术指标转换为自然语言量化报告
- 输入：`KlineData`（Crypto_Klines输出）、`QuestionParsed`（问题解析结果）
- 输出：结构化的中文量化分析报告

**报告内容**：
1. 价格概览（当前价、周期高低点、涨跌幅）
2. 目标价格分析（距离目标百分比、难度评估）
3. 技术指标详情（MACD、RSI、均线、布林带）
4. 综合信号（多空信号计数、整体判断）
5. 量化概率建议（基于技术面的概率调整）

## 工作流架构改进

### 原流程
```
question → [LLM搜索员] → [判定员] → prob
```

### 新流程（Crypto类事件）
```
question
    │
    ├─→ [Crypto_ParseQuestion] → 提取 symbol/target_price
    │         │
    │         ↓
    │   [Crypto_Klines] → 获取K线+技术指标
    │         │
    │         ↓
    │   [Crypto_QuantReport] → 生成量化报告
    │         │
    └─────────┴─→ [判定员] → prob（基于量化数据判断）
```

## 在 PolyMarket_Evaluate 中的应用

### 修改建议

1. **在"初筛"IfNode后添加分支**：
   - 当 `Subject = Crypto` 时，走量化分析路径

2. **连接顺序**：
   ```
   初筛(IsCrypto=true) 
       → Crypto_ParseQuestion(输入: question)
       → Crypto_Klines(输入: binance_symbol)
       → Crypto_QuantReport(输入: klines + parsed)
       → 判定员(输入: 量化报告 + 原始question)
   ```

3. **修改判定员的SystemPrompt**：
   添加对量化报告的理解指令，如：
   ```
   当收到【量化技术分析报告】时，请参考以下规则：
   1. 量化建议概率作为基准参考（权重30%）
   2. 结合技术指标信号调整判断
   3. 若目标距离>30%且处于空头趋势，概率应低于0.30
   4. RSI超卖+MACD金叉可适当上调概率
   ```
